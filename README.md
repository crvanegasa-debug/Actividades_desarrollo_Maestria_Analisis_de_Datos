# Actividades_desarrollo_Maestria_Analisis_de_Datos
Este repositorio contiene las actividades, trabajos y proyectos desarrollados en la asignatura de análisis de datos, enfocados en programas como Python y R.
Entre los cueales podemos identificar el paso a paso para interactuar con estos programas con codigos bases, en un sentido la familiarizacion de comandos para ejecutar algoritmos.
